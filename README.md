# ❤️ HeartFlow Canvas

HeartFlow Canvas is an interactive HTML5 Canvas particle animation that creates a glowing, heart-shaped flow of particles with real-time customization controls. It combines creative coding, smooth animations, and user interaction into a visually immersive experience.

---

## 🌟 Features

- ✨ Heart-shaped particle flow animation  
- 🎨 Multiple particle shapes (Heart, Circle, Star, Square)  
- 🌈 Color schemes: Rainbow, Red, Green, Blue, Monochrome  
- 🌗 Light & Dark theme support  
- 🎛️ Live control panel for real-time customization  
- 🖱️ Mouse & touch interaction with burst effects  
- 🖥️ Fullscreen mode  
- 📱 Fully responsive design  

---

## 🛠️ Built With

- HTML5  
- CSS3  
- Vanilla JavaScript  
- HTML5 Canvas API  

_No external libraries used._
